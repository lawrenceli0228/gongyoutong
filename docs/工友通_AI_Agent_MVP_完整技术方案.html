#决策选择理由一句话
D5技术栈LangGraph + 现成 chat-ui成熟件搭底座,自研只花在亮点
D6范围6 Agent + 深度上限保协同演示价值,砍深度不砍数量
D7慢操作离线预处理 + 小文件同步(图纸≤20MB/文档≤10MB/照片≤10MB 超限自动压缩)不为不存在的负载建队列
D8路由动态路由 + 确定性英雄链演示可靠性靠确定性,智能叙事靠动态
D9部署本地主跑 + 三层兜底演示日不可控因素当需求设计
D10鉴权免登录单用户,安全基线拉满投入匹配实际暴面
D11仓库单仓 + 按 Agent 分包结构即分工,合并冲突≈0
D12基座W1 先落 core/ 四件套(≤4 文件)DRY 红线,防自造框架
D13提示词独立 prompt.md + config 集中常量提示词当文档管,常量当配置管
D14测试全套 + 80% 覆盖率门槛宁多勿少,保住彩排时间
D15评测门槛 = 里程碑验收 + 预定备案提示词质量装硬性仪表盘
D16E2E6 条用户流全自动化E2E 就是可重复执行的彩排
D17→19模型DeepSeek 文本 + Kimi 视觉 + BGE-M3 本地向量负责人指定;视觉与 embedding 缺口提前补上
D18缓存三处「算一次用多次」+ 版本化缓存键性能 / 账单 / 兜底三份收益

      │ artifact_id
      ▼
[Safety Agent · kimi-k3 视觉]
  结构化检查清单 JSON:{违规项[], 位置, 等级, 建议}
      │ 确定性边(代码写死,不经 LLM 决策)
      ▼
[Report Agent · deepseek-v4-flash]
  巡检报告模板填充:隐患汇总+整改建议
      │
      ▼
python-docx 渲染 → artifacts/ 落盘 → 下载卡片
(全程流式播报;任一步失败 → 错误信封 → 中文提示,不静默)

这条链同时证明「多智能体协同」与「工作流自动化」两个评分点;做成确定性子图 = 彩排一百次成功一百次。其余请求仍由 Supervisor 动态路由,展示自主性。

07演示与三层兜底

  • 一键启动:docker-compose up 冷启动 → 首条消息可答(W4 验收项)。
  • 兜底一:手机热点备网络。兜底二:响应缓存——彩排跑过的演示路径断网可复演。兜底三:全程备份录屏。
  • 演示脚本:问答引用 → 英雄链 → CAD 查询 → Schedule 自然语言 → Supervisor 轨迹可视化收尾;彩排 ×2,通过率 100%。

08测试计划(TDD + eval-first)

工具函数 / 解析器走 TDD;提示词走 eval-first(先定评测集与门槛再调 prompt)。E2E 断言只验结构(有隐患卡片 / 有下载链接 / 引用可见),不验 LLM 文案字面。

[核心] llm:正常/超时重试/429退避/缓存 ··············· 单测×4
[核心] artifacts:往返/坏ID/路径穿越拒绝 ············· 单测×3
[编排] 路由20条中文用例(≥90%)/熔断/未知意图 ········ EVAL+单测×2
[英雄链] mock全链出docx / 真实链路 ··················· 集成+E2E
[Safety] 30图评测(≥80%)/超限压缩→通过/压不下→拒/损坏图 · EVAL+单测×4
[Knowledge] 20问答对引用命中(≥80%)/防编造/幂等 ······ EVAL+单测+集成
[Schedule] CRUD×4/中文日期/空结果 ··················· 单测×6
[Report] 模板×2/docx可打开/PDF降级 ·················· 单测×2+集成
[CAD] DXF/GBK样例★/损坏文件/DWG引导/4类查询×2 ······· 单测×8
[E2E] 英雄链/问答引用/CAD/超限报错/断网兜底/重复发送/冷启动冒烟 ×7
合计:单测24 · 集成4 · E2E7 · 评测3套 | 覆盖率≥80% 进 CI
评测门槛 = 里程碑验收(D15):W2 末 Safety ≥80%(不达标 → 触发备案挂检测模型);W3 末路由 ≥90%、RAG ≥80%。达不到当周暴露、当周处理,不拖到演示周。

09失败模式(10/10 三有:有测试·有处理·用户可见)

场景处理用户所见
LLM API 限流 / 超时重试 + 退避 + 缓存「网络繁忙已重试」
Supervisor 死循环recursion_limit=8 熔断友好报错,不烧额度
GBK 中文 DXFezdxf 编码探测(GBK fixture 单测)正常解析

11边界:不做什么 · 复用什么
